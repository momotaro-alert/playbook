# Phase 4 作業ログ（ペットショップ店頭価格）

取得日: 2026-11-02 / 担当: Phase 4（3-7）

## 手順
1. 規約・robots 確認
   - ペットミー: robots.txt は /api/, /pvt/, /shop-admin/ のみ Disallow。利用規約 第4条にスクレイピング禁止条項なし → 取得。2.5秒間隔、UA `Mozilla/5.0 (research; contact via site)`。
   - ブリーダーナビ: 利用規約（https://www.breeder-navi.jp/term 、Inertia.js のため Playwright で描画して確認）禁止事項に「当社コンテンツを、クローリング、スクレイピング等の自動化された手段を用いてデータ収集、抽出、加工、解析または蓄積等をする行為」「データマイニング…」「無断コピー・転載」が明記 → **取得しない**。技術的ブロックではなく規約上の判断。証跡: raw/prices/breedernavi_term_rendered.txt。別の取り方（sitemap/Playwright）も規約の対象なので試していない。
2. ペットミー 全国一覧（都道府県を絞らない `/{dog,cat}/kind-ID/?page=N`）を対象20品種すべて全ページ取得（work/phase4_fetch_petmi.py）。
   - 1ページ30件。親カテゴリ kind（例 トイプードル kind-64）は子カテゴリ（トイ/タイニー/ティーカップ等）を含む。
   - 438ページ、全て HTTP 200。取得カード 12,820件 = 各一覧の総数表示の合計（9,250 + 3,570）と一致。掲載URLで重複除去後 12,815件（ページ送り中の掲載入替によるとみられる重複5件）。
3. 分析（work/phase4_analyze.py）→ clean/ 3ファイル。

## データの性質
- 一覧カードから取得: 品種表記, 住所(都道府県+市区町村), 毛色, 誕生日, 性別, 価格, 税区分, 店舗名, 店舗所在地。
- 税区分: 全12,815件「税込」。価格欠損0件。
- 掲載区分: 全件 店舗ラベル「店舗：」= ペットショップ掲載。ブリーダー直販の掲載は今回の一覧範囲に無し。ブリーダー直販のデータ源（ブリーダーナビ）は規約により取得せず → ブリーダー直販との比較は不可。
- 都道府県: 47都道府県すべて出現（最少 大分15件）。
- 生後日数: 中央値97日、5%点65日、95%点215日。負値1件（生年月日が取得日より後＝誤記の可能性）、56日未満11件 → 明細の備考に注記、負値はビン集計対象外。
- 最低価格 11,000円（Coo&RIKU 等の生後200日超トイプードル）、最高 2,750,000円。外れ値は除外していない（中央値で集計）。

## ビン定義
生後60日=45〜75日、90日=76〜105日、120日=106〜135日、180日=165〜195日、365日=330〜400日（両端含む）。
下落率 = (中央値60日 − 中央値X日)/中央値60日 ×100。両ビン各5件以上の時のみ計算、他は空欄＋備考。

### 注意（解釈上の問題）
- **生後365日ビンは掲載が極端に少ない**（犬21件・猫30件）。1歳前後の個体はペットミー上にほとんど掲載されておらず、売れ残りが一覧から外れる（値下げ後に販売終了・譲渡・掲載停止等）ためと考えられるが、理由は未確認。
- 猫の365日ビン30件中29件が Coo&RIKU で、価格がほぼ一律 220,000円。365日の中央値は1チェーンの価格方針を反映しており、60→365下落率（猫16%前後）は代表性が低い。180日の中央値（猫88,000円）より365日が高いという逆転もこのため。**横断的な値下がりの程度は 60→180日 の方が実態を表す**（犬74%、猫66%）。
- これは同一個体を追跡したものではなく、取得日時点の横断データ。売れ残った個体だけが高月齢ビンに残る生存バイアスあり。
