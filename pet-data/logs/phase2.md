## 3-2 狂犬病予防法
- 厚労省ページ（Shift_JIS）の表を解析。昭和35〜55年は5年刻み、昭和60年以降毎年。**平成8年まで暦年（年末現在）、平成9年度から年度（年度末現在）**。注記※1〜※4を備考に入れた。
- e-Stat 衛生行政報告例（政府統計コード00450027）をサイト検索で辿り、「犬の登録申請数・登録頭数…」表の CSV を 1996年（厚生省報告例 第63表）、2005〜2025年度の 22 本取得。API は appId が無いので使わず、`file-download?statInfId=` の直接DL。
  - **新規登録申請数の列は存在し取得できた**（1996, 2005-2025年度）。1997-2004年度はe-Stat検索（キーワード「狂犬病」「犬の登録申請数」「畜犬」「予防注射済票」「徘徊犬」「抑留」）で該当表が出てこず → **取得失敗**。1997年1-3月分（暦年→年度移行期の端数）はファイルを保存したが CSV には入れていない。
  - 令和6年度から「登録の消除件数（死亡推定によるもの）」列が追加（2024: 37,804、2025: 40,041）。
  - **令和7年度（2025）は厚労省ページ未掲載だが e-Stat で 2026-10-27 公開済み** → 登録頭数等も e-Stat 値で追加。
- 検算（厚労省ページ vs e-Stat 公表当時の全国計）: 1996, 2007, 2009, 2012, 2013, 2015, 2016, 2018, 2019, 2021, 2023, 2024 は登録・注射とも一致。不一致:
  - 2005年度 登録 6,479,977（厚労省）vs 6,670,327（e-Stat）← 19万頭差。注射も 4,796,585 vs 4,924,129。原因不明（厚労省側の後日修正と推測、根拠なし）。
  - 2006（登録102頭差）、2008（注射4,388差）、2010（登録43・注射815差）、2011（注射65,585差：e-Stat 4,920,345）、2014（登録22差）、2017（注射532差＝※4 茨城県修正）、2020（登録17,304・注射49,349差）、2022（登録2,756・注射3,393差）。CSV では厚労省ページ値を採用し e-Stat値は入れていない（新規登録・死亡届出のみ e-Stat）。
- 注射率（計算）を追加。昭和期は注射頭数が登録頭数を上回る（161%など）点を備考に記載。
- 猫は「猫には制度がない」行を入れた。

## 3-3 ペットフード協会
### 取得
- `/pdf/data/{年}/{n}.pdf` を 2013〜2026 × n=1〜（404が2連続で打切）総当たり: **2023（1-13）, 2024（1-13）, 2025（1-16）のみ存在**。2013-2022 は 1.pdf, 2.pdf とも 404。2026 は未公開。
- 旧URL `/data/chart{年}/` は `/data-chart/chart{年}/` へ302 → 404（削除済み）。データ一覧ページ（/data/ と /data-chart/ 同一）は 2024・2025 のリンクのみ。web.archive.org は規約上使用不可。
- `/pdf/data/{2020-2025}/comment.pdf` と `/pdf/data/{2020-2022}/data.pdf` は存在したが「ペットフード産業実態調査（出荷量）」で別調査 → raw/petfood/industry_survey/ に退避（CSV化対象外）。
- **2025年版 PDF は全ファイルで埋め込みフォントに ToUnicode が無く、pdftotext/pdfplumber でテキスト抽出不可**（CID のみ）。埋め込みサブセットフォントの cmap 逆引き（phase2_pdf_cid_text.py）も cmap 無しで失敗。tesseract 無し。→ 必要ページを pdftoppm で PNG 化し**目視転記**（2025/3.pdf p21-25, 34, 38, 39, 41、2025/9.pdf p4-5、2025/14.pdf p2-3）。
  - 検算: 2025年版の時系列表は 2013-2024 も掲載しているので、目視転記した 13 年分のうち 2013-2024 の 12 年分を 2024年版の機械抽出値と突合 → **飼育頭数・飼育率・飼育世帯数・平均頭数・新規系列すべて一致**（転記精度の担保）。年齢構成は各年 合計100±0.2 と 7歳以上計を検算し一致。
### 推計式（新旧）の扱い
- 2024/2025年版の時系列表 2013-2020 の値は「2021年より拡大推計の計算式を改定」した**新式による遡及値**（例: 2020年 犬 7,341千頭）。発表当時（旧式）の 2020年 犬 8,489千頭とは別物 → `推計式` 列で「新式（遡及）」「新式」「旧式（発表当時値）」を分離。
- 旧式の発表当時値は協会資料が削除済みのため**報道・獣医師会雑誌からの二次値**（2008, 2010, 2013-2020）。2009, 2011, 2012 は信頼できる出典を見つけられず**取得失敗**。2008 は獣医師会雑誌の「1,310万頭／1,089万頭」（万単位）。
- **2017年発表時の遡及改定**: nippon.com「犬が前年比43万6000匹減の892万匹」「猫21万7000匹増の952万7000匹」から 2016年値を逆算すると 犬 935.6万・猫 931.0万で、発表当時 2016年値（987.8万・984.7万）と異なる → 2017年版で過去値を改定（獣医師会雑誌の「70歳代のデータを加える（2017年）」と整合）。区分=計算、推計式=「旧式（2017年発表時の遡及改定値）」。
- 推計式の変遷: 協会資料は「2021年改定」、獣医師会雑誌は「沖縄県追加（2013年公表分）／70歳代追加（2017年）／単身・2人以上分離（2022年）」と記載（2022年は2021年調査の公表年と思われる）。
- 新式の内訳（単身・2人以上の世帯数・飼育率・平均頭数・総頭数）を 2024・2025 で記録。協会資料は「千頭」と表記しているが値は頭単位（例 6,820,317）。
### 項目別メモ
- 入手先: 2024年版は「現在飼育者全体（ブースト除く）」で 2023/2024 の2年分。2025年版は全体TOTALの時系列を載せず「1年以内／3年以内飼育開始者（ブースト含む）」の 2023-2025 のみ → 集計ベースが異なるので項目名に（1年以内飼育開始者）等を付けて区別。2013-2022 の入手先は取得失敗（PDF削除）。「譲渡会を通じての無償譲渡」は2024年から新設（2023は「*」）。
- 有償入手率: 人数ベースは Q30（生体入手価格）の `100 − 無償入手 − 覚えていない` で計算（区分=計算）。猫 3年以内飼育開始者 2024 は「覚えていない」が3%未満で非表示のため算出せず空欄。入手先MAの有償7区分の単純合計も別項目で入れた（複数回答なので人数比ではない、と備考）。
- 平均入手価格: 「有償入手者ベース」の平均（万円）。価格帯分布は 3%未満非表示の欠けがあるため CSV 化していない。2023年版 p44-47 の飼育開始時期別（ブースト含む）平均は 2024/2025年版の値（ブースト除く）と基準が違うため採用せず。
- 平均寿命: 2010-2024 は 2024年版 機械抽出、2025 は目視。算出元は「一般世帯で過去10年間に飼育された犬猫」でショップ等での死亡は含まない。
- 年齢構成・純血/雑種: 2019 は 2023年版、2020-2024 は 2024年版、2025 は 2025年版。犬の「純血」にミックス犬を含む。
- 年はすべて「暦年」（調査は各年10月実施。2024年版の調査①は 2024-10-04〜08）。
