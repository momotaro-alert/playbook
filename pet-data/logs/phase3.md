## 再実行手順
```
bash work/phase3_fetch.sh URL raw/<テーマ>/<file>     # 取得（phase2_fetch.sh と同じ仕様、.meta.txt 生成）
python3 -I work/phase3_auction.py    # → clean/オークション_*.csv
python3 -I work/phase3_breeding.py   # → clean/繁殖_業界アンケート.csv, 数値規制スケジュール.csv, 死亡率_国内外比較.csv, 流通調査2002.csv
python3 -I work/phase3_rescue.py     # → clean/保護団体.csv
python3 -I work/phase3_chains.py     # → clean/チェーン_数字.csv, チェーン_公開状況.csv
```
- 共通処理は `work/phase3_common.py`（exec で読み込み。-I でも動く）。
- 各行には「根拠文字列」を持たせ、raw のテキスト（HTML は bs4、PDF は pdfplumber＋pdftotext）に存在するかをスクリプトが検査する。1件でも見つからなければ exit 1。最終実行で4本とも「すべて検出」。
- 例外（目視転記）：Coo&RIKU ウェルネスレポートの画像（raw/chains/cooriku_report_487_w012-1024x428.png）とアニマル・ドネーション白書 p.2 のグラフ（団体種別の保護頭数中央値 11/29/44）。画像転記値は合計・率を assert で検算済み。

### 取れなかった／注意
- 関東・B&Bペットパーク公式（kantobbpetpark.com）：curl は TLS 証明書エラー（unable to get local issuer certificate、http は https へ301）、WebFetch は 503。WebSearch でもキャッシュ等見つからず。→ 二次サイトの「毎週700〜900頭」「毎週約200頭」を区分=二次で採用。TLS 検証の無効化はしていない。
- ピースワンペットパーク：enkara の「毎週約267頭（2018年度 年間22,431頭）」は 22,431÷52≒431 と整合しない。開催回数不明のため 267 をそのまま採用し備考に明記。
